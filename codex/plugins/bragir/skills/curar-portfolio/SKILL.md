# Curar Portfólio

Leia [RUNTIME.md](../../RUNTIME.md) na primeira utilização e o [contrato desta capacidade](../../shared/skills/curar-portfolio/CONTRATO.md). Leia também o [contrato de carreira](../../shared/skills/mapear-perfil-profissional/references/carreira.md) para identidade, versões e estado.

## Execução Codex

Execute o fluxo de domínio com as ferramentas realmente disponíveis. Este entrypoint e RUNTIME.md prevalecem para plataforma, paths e autorização: use AGENTS.md e defaults Codex; traduza recursos legados para shared sem tentar invocar CONTRATO.md como skill. Reutilize autorização já dada para a tarefa local.

Não exija perfil completo, calendário editorial ou vaga quando a tarefa não depender deles. Consulte estado e fontes antes de perguntar. Preserve escrita/voz como capacidade independente e materiais do portfólio no projeto canônico. Registre proposta, aprovação e efeito externo separadamente; não declare publicação/envio sem evidência. Sem acesso externo, entregue o artefato possível e identifique somente o passo dependente como pendente.

## Revisão de portfólio por URL

Para revisão pela ótica de contratação, leia o [método](../../shared/skills/curar-portfolio/references/revisao-contratacao.md), que aponta para rubrica, modelo, fontes e licença. Recupere URL e objetivo existentes antes de perguntar. Só atribua nota total com cobertura suficiente; evidência textual sustenta avaliação parcial, sem inferir qualidade visual ou autoria por IA. Falha de acesso da ferramenta não recebe nota zero. Curadoria de materiais continua possível sem URL.
