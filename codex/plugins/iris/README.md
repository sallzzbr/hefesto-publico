# Iris para Codex

Pacote nativo 0.1.0. Leia o [runtime](RUNTIME.md) e o [guia completo](shared/README.md). Duas skills: `escrever-prompt` e `delegar-agente`. Os princípios e os cartões por destino ficam em [shared/references](shared/references/fontes.md), com fontes e data da consulta.

Sem scripts, hooks ou instalação. O pacote não chama modelos nem escolhe o modelo do executor; recomendações de configuração são texto para quem configura a sessão.
