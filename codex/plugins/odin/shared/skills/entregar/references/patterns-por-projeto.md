# Patterns conhecidos por projeto

> Carregue ao começar a trabalhar num repo — se ele estiver aqui, use os valores sem re-detectar.
> O arquivo cresce com o uso: no primeiro trabalho em cada repo, a skill `entregar` detecta os
> valores, confirma com o usuário e propõe registrar aqui (PR neste plugin).

## Template (copie este bloco por repo)

```markdown
## <nome-do-repo>

- **Branch base:** `<main|master|develop|outra>`
- **Commitlint scopes:** `<lista, ou "não usa">`
- **Validações:** `<comandos de lint / typecheck / test / build, na ordem>`
- **Gate de qualidade:** `<o que precisa estar verde antes de abrir PR>`
- **Idioma commit/PR:** `<pt-BR|en>`
- **Padrões de arquivo:** `<convenções de estrutura/nomenclatura>`
```
