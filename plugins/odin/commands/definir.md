# /definir

Use a skill `definir`.

Pedido inicial: $ARGUMENTS

Valide o gate de entrada (descobertas existem?). Reformule o problema como fenômeno observável,
fixe o placar (métrica, baseline medido agora, alvo, régua fonte+janela+filtro+grão) e escreva
hipóteses falseáveis. Solução técnica pronta ("BFF", refactor, plataforma) entra como desafio
técnico: problema observável + placar técnico + métrica ponte antes de qualquer implementação.
