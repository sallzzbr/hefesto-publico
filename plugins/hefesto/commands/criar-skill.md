# /criar-skill

Invoque a skill `criar-skill`.

Pedido inicial: $ARGUMENTS

Siga o fluxo da skill: coletar plugin de destino, nome, gatilhos e I/O; escrever o SKILL.md no padrão das convenções; atualizar README e versionar (minor).
